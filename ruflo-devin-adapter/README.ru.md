# Ruflo → Devin: полная копия исходников с адаптацией

## Что в архиве

Все отслеживаемые Git файлы исходного Ruflo, включая скрытые каталоги, Rust/TypeScript/JavaScript, документацию, тесты, плагины и лицензии. Не включены история `.git`, `node_modules` и результаты локальной сборки. Точный upstream commit и покомпонентная матрица: `DEVIN-COMPATIBILITY.json`.

Для каждого из 52 исходных манифестов добавлены:

- `.devin-plugin/plugin.json` — отдельный манифест, исходный Claude-манифест сохранён;
- `devin-skills/` — инструкции навыков, команд и ролей агентов в формате SKILL.md. Роли — инструкции, а не нативные агенты Claude; вспомогательные файлы навыков сохранены;
- корневой `hooks.json` — совместимые командные события;
- `devin-adapter/` — мост: имена инструментов, payload, контекст и блокировка;
- `.devin-plugin/mcp.json` там, где есть MCP: отдельная конфигурация для ручного подключения, если хост не обнаружит её автоматически.

Корневой плагин содержит общую библиотеку `.claude` и использует командные хуки современного `ruflo-core`, а не устаревшие bash/jq-хуки. Отдельные плагины доступны по прежним путям `plugins/*`; marketplace-источники вида `directory/` также адаптированы.

## Установка (Devin CLI/Desktop с поддержкой локальных плагинов)

Требуется Node.js 20+, npm; для старых POSIX-хуков — bash и jq. Версии Devin могут иметь различающийся интерфейс: сначала проверьте `devin plugins --help`.

Распакуйте архив в постоянный каталог. Из корня распакованного `ruflo-devin`:

```sh
node --test devin-adapter/test.mjs
# Предпочтительно начать с базового плагина:
devin plugins install --local ./plugins/ruflo-core
# Либо установить общую библиотеку (не вместе с core — дублируются хуки):
# devin plugins install --local .
```

Для остальных компонентов указывайте их каталог, например `./plugins/ruflo-swarm`. Установка каждого плагина отдельно не означает, что все они нужны одновременно. Не устанавливайте одновременно родительский плагин и его `directory/`-вариант.

Проверьте `devin plugins info ruflo-core`, затем начните новую сессию. Этот сценарий установки не выполнялся в настоящем Devin в среде подготовки архива.

### MCP

Не предполагается автоматическая поддержка вложенного `.devin-plugin/mcp.json`. Если сервер не появился в Devin, импортируйте блок `mcpServers` из этого файла через доступные настройки MCP вашего хоста. Для путей `${DEVIN_PLUGIN_ROOT}` вручную подставьте абсолютный путь к соответствующему плагину, если хост не раскрывает переменную.

Для базового сервера это Node-скрипт `plugins/ruflo-core/scripts/mcp-launch.cjs`. Запускайте с рабочим каталогом вашего проекта. Upstream launcher предпочитает установленный CLI и может скачивать `@claude-flow/cli@latest` через npx: это требует сети и не является воспроизводимой фиксацией зависимости. Для контролируемой установки используйте проверенную версию CLI, `RUFLO_MCP_CLI_OVERRIDE` (путь к собранному bin/cli.js) и `RUFLO_MCP_SKIP_NPX=1`.

Не нужно выполнять `npm install` в корне всего монорепозитория только ради загрузки плагинов. Отдельные исходные пакеты имеют собственные инструкции сборки. Нативные/опциональные зависимости, сервисы, ключи API и облачная авторизация не входят в ZIP.

## Границы совместимости — важно

**Это адаптационный слой, а не полная реализация Claude Code внутри Devin.**

- 44 конфигурации содержат function-hook modules: панели, register.ts, monitor streams, UI/toast и API Claude сохранены в исходниках, но не загружаются мостом. Их полноценный перенос требует API расширений интерфейса Devin.
- `PreCompact` не превращается в `PostCompaction`: это разные моменты жизненного цикла. `SubagentStop`, `Notification`, `PermissionRequest`, `PostToolUseFailure`, prompt/agent hooks не исполняются автоматически. Смотрите матрицу.
- Permissions, модель/параллелизм Claude, secret store, `userConfig`, `CLAUDE_ENV_FILE` и расширения UI не переносятся. Секреты настройте через штатное окружение Devin, не вписывайте в архив.
- Поддержка локальных lifecycle hooks в облачных сессиях не гарантируется. Markdown-команды могут содержать инструкции Claude: конвертация сохраняет их как справочные инструкции, не эмулирует инструменты или модель.
- Командные async hooks выполняются синхронно с тайм-аутом: до 15 секунд на команду, 45 секунд на событие. Ошибки/тайм-ауты fail-open с предупреждением в stderr; это не защитная песочница. Явный deny/exit 2 превращается в block; allow и updatedInput не переносятся.
- Хуки исполняют исходные команды репозитория с правами пользователя. Проверьте исходники перед включением. Отключение моста: `RUFLO_DEVIN_HOOKS=0`.

## Проверка

`node --test devin-adapter/test.mjs` — автономные тесты адаптера без npm/network: инструменты, matchers, deny, контекст, тайм-ауты, реальные дочерние процессы, пути с пробелами, буквальная передача опасных shell-символов через stdin и отключение.

Проверены только адаптер и статическая структура. Не заявляется успешный запуск всех upstream-тестов, 52 плагинов, MCP-протокола или UI в Devin. Команда `--list` позволяет увидеть выбранные хуки без исполнения:

```sh
printf '%s' '{"tool_name":"exec","tool_input":{"command":"git status"}}' | node plugins/ruflo-core/devin-adapter/dispatch.mjs PreToolUse --list
```

Полная матрица ограничений — `DEVIN-COMPATIBILITY.json`. Исходная лицензия Ruflo сохранена; адаптация не является официальным релизом Ruflo или Devin.
