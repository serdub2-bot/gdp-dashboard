# Что внутри базы FM2008 8.0.2 (разбор присланных файлов)

Материал получен из архива `inbox/1.zip … 4.zip` (в сумме ~102 МБ распакованных данных)
и папки `db` установленной игры. Ниже — факты, проверенные на этих файлах,
без предположений.

## Формат

Все `.dat` начинаются одинаково: `02 01` + ASCII-метка таблицы (`tad.`) + 3 байта.

- `client_db.dat` и `server_db.dat`: сразу после заголовка идёт **zlib-поток** (`78 9c`),
  который распаковывается целиком (у меня — без потерь, `unused_data` = 0).
  Внутри — бинарные записи фиксированной/переменной длины, текста нет:
  имена хранятся ссылками на таблицу строк.
- `lang_db.dat`: набор **отдельных zlib-чанков**, по одному на язык
  (бельгийские города на английском, немецком, французском, нидерландском…).
  Каждый чанк — таблица строк: `u32 id`, `u32 длина`, затем UTF-16LE текст.

## Что из этого следует

1. **База читается, тексты доступны.** Это важно: значит, можно сверять и готовить
   данные, не запуская Windows-редактор.
2. **Полноценный редактор базы по-прежнему требует Windows.** Числовые записи
   `client_db.dat`/`server_db.dat` — закрытый формат SI, документированного описания
   нет; писать в них «на глаз» опасно для сохранности базы.
3. **Но кое-что можно сделать прямо сейчас, без редактора — через `.edt`-файлы.**
   Игра читает текстовые файлы `data/db/*.edt` при создании новой игры, и они умеют:
   `SWAP_TEAMS` (поменять два клуба дивизионами), `BOOST_TEAM` (репутация, деньги,
   вместимость), `CLUB_DEBT`, `STADIUM_CHANGE_FOR_COMP`.
   Этого достаточно, чтобы **поднять выбранные клубы Третьей лиги в играбельный
   Первый дивизион** — без редактора и без риска для базы.
