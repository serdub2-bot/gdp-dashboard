# Третья лига России — датапак для Football Manager 2008

Данные сезона **2007** (XVI Первенство России среди клубов ЛФЛ, III дивизион) —
именно того сезона, на котором построена база Football Manager 2008.

Источник: [«Любительская футбольная лига 2007»](https://ru.wikipedia.org/wiki/Любительская_футбольная_лига_2007)
(Википедия, CC BY-SA). Итоговые таблицы зон, все участники, места, города.

---

## Сначала — честно о границах возможного

Готового файла базы, который можно просто «подложить» в игру, здесь нет и быть не может:

- **База FM2008 — проприетарный бинарный формат** (файлы `.dat` в папке игры).
  В присланном архиве `inbox/fm.zip` лежит только `fm.exe` — движок, самой базы там нет.
- **Редактор FM2008 — отдельная Windows-программа** (`.NET`, GUI). В этой песочнице
  нет ни Windows, ни Wine, ни дисплея, а базы данных для правки — тем более.
- **Третья лига — 4-й уровень**, а в FM2008 у России всего два уровня
  (Премьер-лига и Первый дивизион). То есть перед «третьей» нужно ещё добавить
  Второй дивизион (3-й уровень) либо заменить клубы в существующем низшем дивизионе.

Поэтому здесь лежит **датапак**: полностью собранный состав лиги в машиночитаемом
виде + порядок действий в редакторе. Это та часть работы, которую можно сделать
без Windows, и самая трудоёмкая — 164 строки клубов, сверенные по зонам.

## Что в комплекте

| Файл | Что внутри |
|---|---|
| `data/clubs_2007.csv` | 164 строки: зона, подзона, место, клуб, город, статус |
| `data/zones_2007.json` | структура: 11 зон, финальный турнир, победитель |
| `data/README.md` | сводка по зонам (генерируется) |
| `src/build.py` | скрипт, собирающий данные из встроенного списка |

Пересобрать: `python3 src/build.py`.

## Как собрать лигу в редакторе FM2008

1. Установите игру и **официальный редактор** (FM Editor 2008) на Windows-машине.
2. В редакторе: `File → Open` → база по умолчанию.
3. Добавьте уровень: `Competitions → Add`, имя `Russian Third Division`,
   нация — Россия, уровень — 4, репутация — низкая.
4. Так как FM не умеет параллельные группы внутри одного турнира, **заведите
   отдельную лигу на каждую зону** (`Third Division — Privolzhye` и т. д., уровень 4).
5. Клубы: `Clubs → Add` → имя, город (`Cities → Add`), стадион, цвета, репутация.
   Города — в колонке `city` файла `clubs_2007.csv`.
6. Заявите клубы в свою зону (вкладка соревнований клуба или список команд лиги).
7. Пропишите повышение: победители зон → стыковые матчи → Второй дивизион.
8. `File → Save As` → новая база; в игре `New Game → Select database`.

Важно: в FM2008 редактор не настолько гибкий, как в поздних версиях, поэтому
самый предсказуемый путь — **заменить клубы существующего низшего дивизиона**,
а не добавлять новый уровень нации.

## Нюансы, которые сэкономят вечер

- **Дубли и вторые команды** (`-2`, `-д`, «мол.», «дубль») в FM не могут играть в
  одном дивизионе с основой. В таблице они есть для полноты — при заведении лиги
  их лучше исключить или отправить в резервный состав.
- **Снявшиеся** команды (Гусев, Квант, Терек-2, Альянс-2) отмечены в колонке
  `status`; их результаты в 2007-м аннулированы.
- **ЮФО** проходил в два этапа — в данных оба, чтобы видеть и заявившихся, и финалистов.
- Часть клубов 2007 года к 2008-му сменила название (например, «Оружейник» Тула →
  «Арсенал»). В базе FM2008 они уже могут существовать — тогда используйте их,
  а не создавайте заново.
- Стадионы и вместимость в датапаке не заполнены: это ещё один проход по
  справочникам, если понадобится.

## Если нужен именно игровой файл

Реальных вариантов два:

1. Собрать в редакторе на Windows по этому датапаку (полчаса-час работы).
2. Взять готовый датапак сообщества с sortitoutsi / FM-форумов, где для FM2008
   уже выложены «Russian Third Division» по зонам, и адаптировать его.

Готов подготовить заготовку в любом удобном формате (XLSX для раскладки по
редактору, JSON для скрипта, отдельные CSV по зонам) — скажите, что удобнее.
