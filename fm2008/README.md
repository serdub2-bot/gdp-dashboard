# FM2008 — работа с базой игры

Всё, что собрано по Football Manager 2008 (база 8.0.2), присланной в `inbox/`.

| Папка | Что внутри |
|---|---|
| [`third-league-russia/`](third-league-russia/) | Третья лига России 2007: 164 клуба по 11 зонам, Excel/CSV, сверка с базой |
| [`second-division-2007/`](second-division-2007/) | Второй дивизион России 2007: 72 клуба, 5 зон, готовые `.edt` для активации |

## Что возможно в FM2008, а что нет

| Задача | Можно? | Как |
|---|---|---|
| Прочитать базу, вытащить все названия | **да** | `tools/lang_scan.py` |
| Поменять клубы дивизионами | **да** | `.edt` → `SWAP_TEAMS` |
| Дать клубу деньги/репутацию/вместимость | **да** | `.edt` → `BOOST_TEAM` |
| Сделать играбельным 3-й уровень (Второй дивизион) | **нет** | в FM2008 нет «Add nation rules» (появилось в FM2010) и нет Add/Remove Leagues (FM2012) |
| Создать новое соревнование | только правкой существующего | Data Editor для Windows |
| Правка `.dat` скриптом | **нет** | закрытый бинарный формат SI, без документации |

Вместо активации 3-го уровня используется перенос клубов Второго дивизиона
в играбельный Первый через `SWAP_TEAMS` — см. [`second-division-2007/`](second-division-2007/).

## Второй дивизион России: совместный патч

Пакет для проверки заполнения клубов —
[`dbpatch/ready/fm2008-second-division-combined.zip`](dbpatch/ready/fm2008-second-division-combined.zip).
Он включает патч `fm.exe` (добавляет пять зон в список) и исправление уровня
этих пяти соревнований в `client_db.dat` и `server_db.dat`. Клубы не переносятся.
Ранее проверялся только `fm.exe`: зоны были видны, но пусты; база отдельно
менялась без регистраций в exe, поэтому совместный вариант не тестировался.
Это экспериментальный пакет — сначала сохраните резервные копии трёх файлов.

Предыдущая попытка заменить флаги соревнований `-1` на `-2` скрывала Россию;
в этом пакете эти флаги не меняются. Формат и код патча разобраны в
[`dbpatch/`](dbpatch/README.md).
