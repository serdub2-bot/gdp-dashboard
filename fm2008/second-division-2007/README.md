# Второй дивизион России — сделать играбельным в FM2008

Данные сезона **2007** (третий уровень, 5 зон, 72 клуба) и готовые `.edt`-файлы,
которые поднимают клубы Второго дивизиона в играбельный Первый.

Источник таблиц: [2007 Russian Second Division](https://en.wikipedia.org/wiki/2007_Russian_Second_Division),
[2007 Russian First Division](https://en.wikipedia.org/wiki/2007_Russian_First_Division) (CC BY-SA).

---

## Сначала главное: «активировать» дивизион в FM2008 нельзя

Проверил по документации и сообществу:

- **Add/Remove Leagues** (добавить лигу в сохранение) появился только в FM2012;
  в FM2008 смена набора играбельных лиг невозможна после старта игры.
- **«Add nation rules» → «Add lower divisions and cups»** в редакторе — это FM2010
  и новее. В редакторе FM2008 такого нет: он умеет править существующие
  соревнования, но не создавать новый уровень нации.
- Поэтому «активный Второй дивизион» в FM2008 штатно не включается — ни файлом,
  ни настройкой.

## Что можно сделать и что здесь лежит

Рабочий обходной путь: **`SWAP_TEAMS`** — поменять клубы Второго дивизиона местами
с клубами Первого. Первый дивизион играбельный, значит поднятые клубы становятся
играбельными: за них можно взять команду, у них полноценный матч-движок.

Ограничение: в Первом дивизионе **22 места**, поэтому за один файл поднимается
одна зона (11–16 клубов). Пять файлов — пять вариантов на выбор, ставить нужно
**один**.

| Зона | Клубов | Файл |
|---|---|---|
| Юг | 15 | `edt/second_division_yug.edt` |
| Запад | 16 | `edt/second_division_zapad.edt` |
| Центр | 16 | `edt/second_division_centr.edt` |
| Урал-Поволжье | 14 | `edt/second_division_ural-povolzhye.edt` |
| Восток | 11 | `edt/second_division_vostok.edt` |

Всего 72 строки `SWAP_TEAMS`. Внутри каждой зоны клубы расставлены так, чтобы
резерв не менялся местами со своей же основой (например, «Балтика-2» не свапается
с «Балтикой»).

## Как применить

1. Возьмите **один** `.edt` из `edt/`.
2. Скопируйте в `<папка игры>\data\db\` (там же, где `802.xml` и `.dat`).
3. Запустите игру → **New Game**. Старые сохранения не меняются, `.edt` читается
   только при создании новой игры.
4. Клубы зоны теперь в Первом дивизионе — выбирайте любой.

Если строка не сработала (клуб остался на месте) — имя не совпало с игровым.
Тогда: *Preferences → Show Unique IDs*, открыть клуб, взять его ID и заменить
название в `.edt` на это число.

## Что подтверждено базой

Скрипт сверяет названия с русской таблицей строк из `lang_db.dat` вашей базы 8.0.2
(отчёт: [`data/swap_report.md`](data/swap_report.md)). Статусы в отчёте:

- **подтверждено** — и город, и первое слово названия клуба есть в базе;
- **город есть, название клуба — проверить**;
- **проверить по ID в игре**.

## Состав

| Файл | Что |
|---|---|
| `data/second_division_2007.csv` | 72 клуба: зона, место, клуб, город |
| `data/first_division_2007.csv` | 22 клуба Первого дивизиона 2007 |
| `data/swap_report.md` | по каждой зоне: кто с кем меняется и статус сверки |
| `edt/*.edt` | готовые файлы для игры |
| `src/build.py` | пересобрать CSV |
| `src/make_swaps.py` | пересобрать `.edt` (+ сверка с `lang_db.dat`) |

```bash
python3 src/build.py
python3 src/make_swaps.py --lang-db "/путь/к Football Manager 2008/data/db/lang_db.dat"
# только одна зона и с усилением финансов/репутации:
python3 src/make_swaps.py --zone Запад --boost --money 300000 --reputation 2000
```

## Чего этот способ не даёт

- Полноценного 3-го уровня с повышением/понижением между Вторым и Первым
  дивизионами — движок FM2008 так не умеет.
- Всех 72 клубов одновременно играбельными: мест 22, поэтому одна зона за раз.
- Замены соревнования «Второй дивизион» на «Третью лигу» — для этого нужен
  редактор и версия игры новее.

Если нужен именно настоящий 3-й уровень — это FM2010+ с редактором наций,
либо FM24 с датапаком «Россия до Третьей лиги» от сообщества.
