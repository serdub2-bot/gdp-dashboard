# inbox — папка для передачи файлов

Сюда можно загружать любые файлы прямо через сайт GitHub: видео, PDF, архивы,
документы, звук. Из чата вложения принимаются только как изображения, а через
GitHub проходит всё.

## Как загрузить

1. Откройте страницу загрузки для этой ветки:

   https://github.com/serdub2-bot/gdp-dashboard/upload/arena/38de8519-gdp-dashboard/inbox

   (или: в папке `inbox` на GitHub → **Add file → Upload files**)

2. Перетащите файл в окно браузера.
3. Внизу нажмите **Commit changes** (ветка должна остаться
   `arena/38de8519-gdp-dashboard`).
4. Напишите в чате имя файла — его заберут и обработают.

## Ограничения

| Способ | Максимальный размер одного файла |
|---|---|
| Загрузка через сайт GitHub | 25 МБ |
| Обычный `git push` | 100 МБ |
| GitHub Release (assets) | 2 ГБ |

Если файл больше 25 МБ, удобнее залить его через `git`:

```bash
git clone https://github.com/serdub2-bot/gdp-dashboard.git
cd gdp-dashboard
git checkout arena/38de8519-gdp-dashboard
cp /путь/к/файлу inbox/
git add inbox/файл && git commit -m "add file" && git push
```

## Что удобно передавать

- исходники фото в полном разрешении (RAW, TIFF, PNG, HEIC);
- видео и звук для обработки;
- документы Word/PDF, таблицы, архивы;
- большие наборы данных (лучше ZIP).

Загруженное не обязательно оставлять в репозитории навсегда — после обработки
файлы можно удалить отдельным коммитом.
